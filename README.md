# 三国杀房间监控助手

当前版本：**0.14.6**

这是一个 Edge 浏览器扩展，用来筛选三国杀网页大厅中的房间，并把符合条件的等待房间用绿色高亮出来。

插件直接读取游戏大厅里的公开房间信息，不需要安装本地服务，也不会自动进房。

## 安装

1. 打开 `edge://extensions/`。
2. 打开“开发人员模式”。
3. 点击“加载解压缩的扩展”。
4. 选择项目里的 `extension` 文件夹。
5. 打开三国杀网页并进入房间大厅。

更新版本后，请先在扩展页面点击“重新加载”，再刷新一次游戏页面。

## 使用

游戏右下角会显示“房间监控”浮窗：

1. 选择玩法，默认是“身份标准”。
2. 设置出手时间，默认 15 秒。
3. 设置当前人数区间，默认 1～8 人；用三段按钮设置密码、禁聊和道具条件。
4. 点击“刷新并检测”。
5. 符合全部条件的等待房间会显示绿色高亮。

检测成功后，游戏大厅推送房间变化时会自动更新高亮，不需要反复点击刷新。

## 浮窗操作

- 拖动标题栏可以移动浮窗。
- 点击 `−` 收起，点击 `＋ 展开` 展开。
- 展开宽度约 292px，收起宽度约 170px；表单改为纵向单列。
- 浮窗位置、收起状态和筛选条件会自动保存。
- 自动刷新默认开启，间隔默认 5 秒，可设置为 5～15 秒。
- 进度条显示距离下一次自动刷新的剩余时间。
- 点击“刷新并检测”只执行一次刷新，并关闭自动刷新。
- 自动刷新找到符合条件的房源后会关闭自动刷新，并隐藏刷新进度。
- 页面切到后台时倒计时暂停，回到游戏后从剩余时间继续。
- 刷新按钮固定在浮窗底部，出现错误时标题旁会显示红点。

## 没有高亮或浮窗不见

1. 到 `edge://extensions/` 重新加载扩展。
2. 刷新游戏页面。
3. 点击浏览器工具栏中的插件图标。
4. 点击“复制 Log”，把日志发给开发者。

扩展菜单只提供版本信息和日志复制，筛选与刷新都在游戏内浮窗完成。
